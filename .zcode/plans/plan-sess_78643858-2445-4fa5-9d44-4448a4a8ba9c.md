# Modernization plan — manjeetshinde.github.io

Work happens on the current `develop` branch; **no commits or pushes** unless you ask. Phased exactly as the brief demands: platform first, redesign only after the upgraded baseline builds.

## Audit findings (what drives this plan)

- **Next 15.3.4** pinned; [Next.js 16.3.5 is Active LTS](https://endoflife.date/nextjs) and the [August 2026 security release fixed two Critical vulnerabilities](https://nextjs.org/blog) — 15.x reaches EOL 2026-10-21. Next 16 removes `next lint` (ESLint CLI required), defaults to Turbopack, and pairs with React 19.2.
- **CI is broken-by-design**: workflow runs `npm ci` and caches on `package-lock.json`, but the repo is pnpm-only (`pnpm-lock.yaml`, `packageManager: pnpm@10.8.0`). It also pins **Node 20, which reached EOL April 2026**. [Node 24 is the Active LTS](https://nodejs.org/en/about/previous-releases).
- **Wrong `basePath`**: `next.config.ts` prefixes `/manjeetshinde.github.io` — a project-site pattern. This is a user site served at the root, so production assets currently point at 404 URLs.
- **Dead code / unused weight**: 4 of 5 background components commented out (plus a byte-identical duplicate file), dead exports in `3d-card.tsx`, commented blocks in pages, unused shadcn token boilerplate. Unused deps: `lucide-react`, `class-variance-authority` (never imported); after redesign also `react-icons`, `clsx`, `tailwind-merge`, `tw-animate-css`.
- **Content**: 28 projects inline in `ProjectList.tsx` with data bugs (`httpss://` typo, `"#"` placeholder hrefs); no `not-found.tsx`, `sitemap.ts`, `robots.ts`, canonical/OG metadata; 452 KB / 1993 px portrait rendered at 400 px; copy full of banned phrases ("Hello there!", "my own little tech adventure", "stay tuned"); black + aurora-blob + glassmorphism aesthetic — all contrary to the brief.
- No framer-motion / three.js anywhere (good — nothing to unwind there).

## Phase B — Design direction and implementation

**Direction chosen** (reasoned through A ultra-minimal editorial / B technical-index / C restrained experimental): **A as the base with selective B elements** — a warm off-white / graphite editorial system (highest credibility, timelessness, readability; lowest complexity and payload) with index-like work rows and monospace metadata labels borrowed from B. Light theme only — one excellent theme, no toggle infrastructure. No Three.js (no candidate interaction passes all the brief's conditions; CSS is sufficient).

**Typography**: one sans family for body (Inter, kept via `next/font`, self-hosted) + one editorial serif for display headings (via `next/font`, latin subset, variable) + system `ui-monospace` stack for labels/dates/metadata. Zero external font requests at runtime.

**Tokens** (Tailwind v4 `@theme` in `globals.css`, replacing the unused shadcn boilerplate): paper (warm off-white), ink (graphite), muted, hairline borders, one restrained rust accent used only for interactive markers; near-zero radius; deliberate type scale. Subtle `::selection` styling as a personality detail. `prefers-reduced-motion` respected (the few transitions are CSS-only, hundreds-of-ms).

**Content architecture** — all Server Components, target of **zero `"use client"` files**:

```
src/
├── app/
│   ├── layout.tsx      # fonts, full metadata, <SiteHeader/> <SiteFooter/>
│   ├── page.tsx        # hero · selected work · now
│   ├── work/page.tsx   # full editorial index of all 28 projects
│   ├── not-found.tsx   # restrained static 404
│   ├── sitemap.ts      # root-origin URLs
│   ├── robots.ts
│   └── globals.css     # tokens only — no shadcn/sidebar/chart boilerplate
├── components/
│   ├── site-header.tsx  # name + Work / GitHub↗ / Procillage↗ — no JS menu
│   ├── site-footer.tsx  # socials as text links w/ inline SVG arrows, microcopy
│   └── work-row.tsx     # editorial row: name · context · one sentence · status/link
└── lib/
    ├── site.ts          # name, canonical URL, socials, email

```
